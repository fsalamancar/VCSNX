# VCSNX Plan 1 (H0–H3): de la preparación a la primera imagen en la Switch

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Que GTA: Vice City Stories (recompilado con PSPRecomp) arranque en la Switch como `.nro`, con el dibujado por CPU, los Joy-Con funcionando y `perf.log` con números de rendimiento de 3 escenas.

**Architecture:**
- El código del fork OverkillLabs3 se importa a `vendor/` y se toca lo mínimo: 4 parches chicos, todos listados en `UPSTREAM.md`.
- Todo lo nuevo vive en `platform/switch/`:
  - ventana SDL2;
  - GPU "vacía";
  - controles;
  - hilos con núcleo fijo y pila grande;
  - registro de rendimiento;
  - chequeos de arranque.
- Esa misma capa compila en el Mac (banco de pruebas) y en la Switch. Las únicas excepciones son los archivos `nx_*.cpp`, que son solo de la Switch.
- El código traducido del juego se regenera en local a partir del `EBOOT.BIN` del usuario y nunca entra al repo.

**Tech Stack:**
- C++20.
- CMake ≥ 3.25 con presets y Ninja.
- Mac: Apple clang, Homebrew (SDL2, FFmpeg).
- Switch: devkitPro (devkitA64 GCC, libnx, switch-sdl2, switch-mesa, switch-ffmpeg).
- Python 3, solo biblioteca estándar, para las herramientas.

**Spec:** `docs/superpowers/specs/2026-10-11-vcsnx-switch-port-design.md`

**Convenciones del plan:**
- **USUARIO:** el paso lo hace el usuario, en su Terminal o en la consola. El agente le da el comando exacto y espera la confirmación o la salida.
- Todo lo demás lo ejecuta el agente desde `~/Documents/GitHub/VCSNX`.
- Cada commit termina con la línea `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. En los comandos aparece como segundo `-m`.
- Datos del usuario usados en el plan: `PSP_DATA=~/VCSNative/PSP_DATA`.

## Global Constraints

- **Versión del juego:** solo ULUS-10160. ELF descifrados aceptados (SHA-256):
  - `85c5e172fa0207086b72a37649e9a10d47845f0866b0dee179c48d930e43d17f` (`PSP_DATA/EBOOT.BIN`);
  - `fee2e86c7fe457ab6da463d9fdc16f156a0900adcdaa2fd260206c11907c5d65` (`PSP_GAME/SYSDIR/BOOT.BIN`).
- **Fork:** `https://github.com/OverkillLabs3/vice-city-stories-recomp`, commit `b5a861d200ad66a126d51ec2fcef56b0455e4daf`.
- **Original:** `https://github.com/jessicanataliagta/PSPRecomp`, commit `f6e7d415c7f447b934cc3865a31eb725f353d659`.
- **Generador:** `vcs_recomp <ELF> --auto <dir> 0x08804000 16384`. La referencia es el `generated/` del original: 237 archivos.
- **Nunca se suben al repo:**
  - archivos del juego;
  - `generated/`;
  - `.nro`, `.nacp`, `.exe`, `.dll`;
  - logs.

  Todo cambio dentro de `vendor/` se anota en `UPSTREAM.md`.
- **Datos en la Switch:** todo en `sdmc:/switch/vcsnx/`:
  - `PSP_DATA/`;
  - `VCSNative.ini`;
  - `perf.log`;
  - `vcsnx_stderr.log`;
  - `VCSNative.log`.
- **Compilación:** `platform/switch/` compila en el Mac y en la Switch; solo `nx_*.cpp` es exclusivo de la Switch.
- **Dibujado:** solo `Backend=Software` en la etapa 1. No hay GPU (todas las funciones `ge_gpu_backend_*` dicen "inactiva").
- **Controles (spec §5):**
  - × = B, ○ = A, □ = Y, △ = X.
  - L/R = L/R, + = Start, − = Select.
  - Stick izquierdo = stick PSP, cruceta = cruceta, stick derecho = cámara.
  - ZL/ZR: a pie repiten L/R; en vehículo, ZR acelera y ZL frena (comportamiento del fork).
- **Núcleos:** 3 para la aplicación.
  - Núcleo 0: hilo principal (SDL y presentación).
  - Núcleo 1: el juego.
  - Núcleo 2 y luego 0: los 2 hilos de ayuda del rasterizador (`PSPRECOMP_RASTER_THREADS=3`).
- **`perf.log`:** una línea cada 10 s con:
  - FPS promedio y mínimo;
  - ms del juego, del GE/rasterizador y de presentación, cada uno promedio y máximo;
  - pico de memoria en MB.
- **Meta de H3:** medir. La meta de ≥ 30 FPS en portátil se decide en H4, que no forma parte de este plan.
- **Modo de ejecución:** solo modo aplicación (forwarder de Sphaira, o R al iniciar un juego). En modo applet o sin datos aparece un mensaje claro en ASCII y el juego se cierra con +.
- **NACP:** nombre "GTA Vice City Stories", autor "VCSNX (PSPRecomp port)", versión `PROJECT_VERSION` (0.1.0).

```bash
#!/usr/bin/env bash
# Checks every tool VCSNX Plan 1 needs on the Mac (host build + devkitPro Switch build).
# Prints one line per check. Exits 0 only when nothing required is missing; WARN lines
# (video decoders, needed from H5 on) do not fail the check.
set -u
DKP="${DEVKITPRO:-/opt/devkitpro}"
PORTLIBS="$DKP/portlibs/switch"
export PKG_CONFIG_PATH="/opt/homebrew/opt/ffmpeg@7/lib/pkgconfig:/opt/homebrew/lib/pkgconfig${PKG_CONFIG_PATH:+:$PKG_CONFIG_PATH}"
missing=0

check() { # description, command...
    local description="$1"; shift
    if "$@" >/dev/null 2>&1; then echo "ok      $description"; else echo "MISSING $description"; missing=1; fi
}
warn_check() { # description, command...
    local description="$1"; shift
    if "$@" >/dev/null 2>&1; then echo "ok      $description"; else echo "WARN    $description"; fi
}

echo "== Mac host"
for tool in cmake ninja pkg-config python3 git rsync; do check "$tool" command -v "$tool"; done
echo "info    $(cmake --version 2>/dev/null | head -1)"
check "sdl2 (pkg-config)" pkg-config --exists sdl2
check "ffmpeg libs (pkg-config)" pkg-config --exists libavformat libavcodec libswscale libswresample libavutil
echo "info    host libavcodec $(pkg-config --modversion libavcodec 2>/dev/null || echo none)"

echo "== devkitPro"
check "aarch64-none-elf-g++" test -x "$DKP/devkitA64/bin/aarch64-none-elf-g++"
check "Switch.cmake" test -f "$DKP/cmake/Switch.cmake"
check "elf2nro" test -x "$DKP/tools/bin/elf2nro"
check "nxlink" test -x "$DKP/tools/bin/nxlink"
check "libnx" test -f "$DKP/libnx/lib/libnx.a"
check "switch pkg-config" test -x "$PORTLIBS/bin/aarch64-none-elf-pkg-config"
check "switch-sdl2" test -f "$PORTLIBS/lib/libSDL2.a"
check "switch-mesa (libEGL)" test -f "$PORTLIBS/lib/libEGL.a"
check "switch-ffmpeg (libavcodec)" test -f "$PORTLIBS/lib/libavcodec.a"
check "cmake helper nx_create_nro" grep -rqs "nx_create_nro" "$DKP/cmake"
check "cmake helper nx_generate_nacp" grep -rqs "nx_generate_nacp" "$DKP/cmake"
check "cmake system name NintendoSwitch" grep -rqs "NintendoSwitch" "$DKP/cmake"
echo "info    $("$DKP/devkitA64/bin/aarch64-none-elf-gcc" --version 2>/dev/null | head -1)"
major="$(sed -n 's/^#define LIBAVCODEC_VERSION_MAJOR *\([0-9]*\).*/\1/p' "$PORTLIBS/include/libavcodec/version_major.h" 2>/dev/null)"
echo "info    switch libavcodec major ${major:-unknown} (vendor code targets 61 = FFmpeg 7)"

echo "== switch-ffmpeg pieces used by vcs_media_decoder.cpp (needed from H5)"

for sym in ff_h264_decoder ff_atrac3p_decoder ff_mpegps_demuxer; do
    warn_check "$sym" sh -c "\"$NM\" -g \"$PORTLIBS/lib/libavcodec.a\" \"$PORTLIBS/lib/libavformat.a\" 2>/dev/null | grep -Eq ' [DR] $sym\$'"
done
exit "$missing"
```

```bash
# Pinned sources for VCSNX (spec §2.1). Sourced by tools/import_vendor.sh and tools/fetch_upstream.sh.
FORK_URL=https://github.com/OverkillLabs3/vice-city-stories-recomp.git
FORK_COMMIT=b5a861d200ad66a126d51ec2fcef56b0455e4daf
UPSTREAM_URL=https://github.com/jessicanataliagta/PSPRecomp.git
UPSTREAM_COMMIT=f6e7d415c7f447b934cc3865a31eb725f353d659

# fetch_pinned <url> <commit> <dest>: shallow-fetches exactly <commit> into a fresh <dest>.
fetch_pinned() {
    local url="$1" commit="$2" dest="$3"
    rm -rf "$dest"
    git init -q "$dest"
    git -C "$dest" remote add origin "$url"
    git -C "$dest" fetch -q --depth 1 origin "$commit"
    git -C "$dest" checkout -q FETCH_HEAD
    if [ "$(git -C "$dest" rev-parse HEAD)" != "$commit" ]; then
        echo "fetched commit does not match $commit" >&2
        return 1
    fi
}
```

- [ ] **Step 2: Escribir `tools/import_vendor.sh`**

```bash
#!/usr/bin/env bash
# Imports the pinned PSPRecomp fork into vendor/vcs-recomp without generated code or prebuilt
# binaries, plus upstream's optimize_generated_*.py passes. Re-running replaces vendor/vcs-recomp.
set -euo pipefail
ROOT="$(cd "$(dirname "$0")/.." && pwd)"
# shellcheck source=tools/lib/pinned.sh
. "$ROOT/tools/lib/pinned.sh"
WORK="$(mktemp -d)"
trap 'rm -rf "$WORK"' EXIT

fetch_pinned "$FORK_URL" "$FORK_COMMIT" "$WORK/fork"
fetch_pinned "$UPSTREAM_URL" "$UPSTREAM_COMMIT" "$WORK/upstream"

DEST="$ROOT/vendor/vcs-recomp"
rm -rf "$DEST"
mkdir -p "$DEST"
rsync -a \
    --exclude='.git/' \
    --exclude='profiles/vcs/generated/' \
    --exclude='profiles/vcs/third_party/ffmpeg/bin/' \
    --exclude='profiles/vcs/third_party/ffmpeg/lib/' \
    --exclude='*.dll' --exclude='*.lib' --exclude='*.exe' \
    "$WORK/fork/" "$DEST/"
for pass in cross_unit_hot_regs fpr_blocks gpr_blocks; do
    cp "$WORK/upstream/profiles/vcs/tools/optimize_generated_${pass}.py" "$DEST/profiles/vcs/tools/"
done

# Guards: nothing derived from the game and no Windows binaries may land in vendor/.
if [ -e "$DEST/profiles/vcs/generated" ]; then echo "generated/ was imported" >&2; exit 1; fi
if find "$DEST" -type f \( -iname '*.dll' -o -iname '*.lib' -o -iname '*.exe' \) | grep -q .; then
    echo "a prebuilt binary was imported" >&2; exit 1
fi
echo "imported fork $FORK_COMMIT (+ optimizers from $UPSTREAM_COMMIT): $(find "$DEST" -type f | wc -l | tr -d ' ') files, $(du -sh "$DEST" | cut -f1)"
```

```python
"""Compare two directory trees file by file by SHA-256 (stdlib only).

Usage: python3 -I tools/compare_trees.py <reference_dir> <candidate_dir>
Exit status: 0 when both trees hold exactly the same files with identical bytes,
1 when they differ, 2 when an argument is not a directory.
"""
from __future__ import annotations

import argparse
import hashlib
import sys
from dataclasses import dataclass
from pathlib import Path


@dataclass(frozen=True)
class TreeDiff:
    identical: tuple[str, ...]
    different: tuple[str, ...]
    missing: tuple[str, ...]  # in reference, absent from candidate
    extra: tuple[str, ...]  # in candidate, absent from reference

    @property
    def matches(self) -> bool:
        return not (self.different or self.missing or self.extra)


def _digest(path: Path) -> str:
    sha = hashlib.sha256()
    with path.open("rb") as handle:
        for chunk in iter(lambda: handle.read(1 << 20), b""):
            sha.update(chunk)
    return sha.hexdigest()


def _files(root: Path) -> dict[str, Path]:
    return {path.relative_to(root).as_posix(): path for path in sorted(root.rglob("*")) if path.is_file()}


def compare_trees(reference: Path, candidate: Path) -> TreeDiff:
    """Classify every file of both trees as identical, different, missing or extra."""
    ref, cand = _files(reference), _files(candidate)
    identical: list[str] = []
    different: list[str] = []
    for name in sorted(ref.keys() & cand.keys()):
        (identical if _digest(ref[name]) == _digest(cand[name]) else different).append(name)
    return TreeDiff(
        identical=tuple(identical),
        different=tuple(different),
        missing=tuple(sorted(ref.keys() - cand.keys())),
        extra=tuple(sorted(cand.keys() - ref.keys())),
    )


def main(argv: list[str] | None = None) -> int:
    parser = argparse.ArgumentParser(description="Compare two directory trees by SHA-256.")
    parser.add_argument("reference", type=Path)
    parser.add_argument("candidate", type=Path)
    args = parser.parse_args(argv)
    for directory in (args.reference, args.candidate):
        if not directory.is_dir():
            print(f"not a directory: {directory}", file=sys.stderr)
            return 2
    result = compare_trees(args.reference, args.candidate)
    print(f"identical={len(result.identical)} different={len(result.different)} "
          f"missing={len(result.missing)} extra={len(result.extra)}")
    for label, names in (("different", result.different), ("missing", result.missing), ("extra", result.extra)):
        for name in names:
            print(f"{label}: {name}")
    return 0 if result.matches else 1


if __name__ == "__main__":
    sys.exit(main())
```

```cpp
namespace vcsnx {

enum class ThreadRole {
    Guest,        // the PSP interpreter thread started by main.cpp
    RasterWorker, // ge_renderer.cpp RowWorkerPool helpers; index runs 1..N-1
};

// Core a thread should run on. A Switch application owns cores 0-2: core 0 keeps the main
// thread (SDL events and presentation), the guest gets core 1 to itself, and raster workers
// take core 2 first and then wrap onto core 0.
[[nodiscard]] int core_for_thread(ThreadRole role, unsigned index) noexcept;

// Pins the calling thread to core_for_thread(role, index) on the Switch; no-op elsewhere.
void pin_current_thread(ThreadRole role, unsigned index) noexcept;

// The guest thread: a 16 MiB stack (the Windows build links a 64 MB main stack; default
// secondary-thread stacks are far smaller) and pinned as ThreadRole::Guest. Same shape as the
// std::thread it replaces in main.cpp: construct to start, join() to wait.
class GuestThread {
public:
    explicit GuestThread(std::function<void()> body);
    GuestThread(const GuestThread &) = delete;
    GuestThread &operator=(const GuestThread &) = delete;
    ~GuestThread();

    void join();

private:
    pthread_t thread_{};
    bool joinable_{false};
};

} // namespace vcsnx
```

```cpp
#if defined(__SWITCH__)
#include <switch.h>

namespace vcsnx {
namespace {

constexpr std::size_t kGuestStackBytes = 16u * 1024u * 1024u;

struct GuestStart {
    std::function<void()> body;
};

void *guest_entry(void *raw) {
    std::unique_ptr<GuestStart> start(static_cast<GuestStart *>(raw));
    pin_current_thread(ThreadRole::Guest, 0u);
    start->body();
    return nullptr;
}

} // namespace

int core_for_thread(ThreadRole role, unsigned index) noexcept {
    switch (role) {
    case ThreadRole::Guest:
        return 1;
    case ThreadRole::RasterWorker:
        return (index % 2u == 1u) ? 2 : 0;
    }
    return 0;
}

void pin_current_thread(ThreadRole role, unsigned index) noexcept {
#if defined(__SWITCH__)
    const int core = core_for_thread(role, index);
    (void)svcSetThreadCoreMask(CUR_THREAD_HANDLE, core, 1u << core);
#else
    (void)role;
    (void)index;
#endif
}

GuestThread::GuestThread(std::function<void()> body) {
    pthread_attr_t attributes;
    pthread_attr_init(&attributes);
    pthread_attr_setstacksize(&attributes, kGuestStackBytes);
    auto *start = new GuestStart{std::move(body)};
    const int result = pthread_create(&thread_, &attributes, &guest_entry, start);
    pthread_attr_destroy(&attributes);
    if (result != 0) {
        delete start;
        throw std::runtime_error("pthread_create failed for the guest thread");
    }
    joinable_ = true;
}

GuestThread::~GuestThread() {
    join(); // never leave a running guest behind (std::thread would call std::terminate)
}

void GuestThread::join() {
    if (!joinable_) return;
    pthread_join(thread_, nullptr);
    joinable_ = false;
}

} // namespace vcsnx
```

```cpp
#include "pad_mapping.hpp"

#include <algorithm>
#include <cmath>
#include <cstdlib>

namespace vcsnx {
namespace {

// Same dead zone and scaling as the fork's SDL layer (platform/macos/display_window_sdl.cpp).
constexpr int kDeadZone = 7849;

float axis_with_deadzone(std::int16_t raw) noexcept {
    int magnitude = std::abs(static_cast<int>(raw));
    if (magnitude <= kDeadZone) return 0.0f;
    magnitude = (magnitude - kDeadZone) * 32767 / (32767 - kDeadZone);
    return static_cast<float>(raw < 0 ? -magnitude : magnitude) / 32767.0f;
}

std::uint8_t stick_to_psp(float normalized) noexcept {
    return static_cast<std::uint8_t>(
        std::clamp(128 + static_cast<int>(std::lround(normalized * 127.0f)), 0, 255));
}

int camera_axis(float normalized) noexcept {
    return std::clamp(static_cast<int>(std::lround(normalized * 127.0f)), -127, 127);
}

} // namespace

vcs::HostInputState map_pad_to_psp(const PadSample &pad, const PadMappingOptions &options) noexcept {
    vcs::HostInputState input{};
    if (!pad.connected) return input;
    const auto held = [&pad](std::uint32_t button) { return (pad.buttons & button) != 0u; };

    if (held(kPadB)) input.buttons |= kPspCross;
    if (held(kPadA)) input.buttons |= kPspCircle;
    if (held(kPadY)) input.buttons |= kPspSquare;
    if (held(kPadX)) input.buttons |= kPspTriangle;
    if (held(kPadL)) input.buttons |= kPspLTrigger;
    if (held(kPadR)) input.buttons |= kPspRTrigger;
    if (held(kPadPlus)) input.buttons |= kPspStart;
    if (held(kPadMinus)) input.buttons |= kPspSelect;
    if (held(kPadUp)) input.buttons |= kPspUp;
    if (held(kPadDown)) input.buttons |= kPspDown;
    if (held(kPadLeft)) input.buttons |= kPspLeft;
    if (held(kPadRight)) input.buttons |= kPspRight;

    if (!options.driving) {
        if (held(kPadZL)) input.buttons |= kPspLTrigger;
        if (held(kPadZR)) input.buttons |= kPspRTrigger;
    }
    input.accelerate = held(kPadZR);
    input.brake = held(kPadZL);

    const float left_x = axis_with_deadzone(pad.left_x);
    const float left_y = axis_with_deadzone(pad.left_y);
    if (left_x != 0.0f || left_y != 0.0f) {
        input.analog_x = stick_to_psp(left_x);
        input.analog_y = stick_to_psp(left_y); // pad and PSP both grow downward
```

```cpp
// The fields VCSNX uses from one "[frame-time]" line (vcs_profile.cpp, PSPRECOMP_FRAME_TIME_DIAG).
struct FrameTimeSample {
    std::uint64_t frame_us{};
```

```cpp
#include "perf_log.hpp"

#include <algorithm>
#include <charconv>
#include <cstdio>
#include <system_error>

namespace vcsnx {

std::optional<FrameTimeSample> parse_frame_time_line(std::string_view line) {
    constexpr std::string_view kPrefix = "[frame-time] ";
    if (line.substr(0, kPrefix.size()) != kPrefix) return std::nullopt;
    line.remove_prefix(kPrefix.size());

    FrameTimeSample sample;
    bool have_frame = false;
    while (!line.empty()) {
        const std::size_t space = line.find(' ');
        const std::string_view token = line.substr(0, space);
        line = space == std::string_view::npos ? std::string_view{} : line.substr(space + 1u);
        const std::size_t equals = token.find('=');
        if (equals == std::string_view::npos) continue;
        const std::string_view key = token.substr(0, equals);
        const std::string_view text = token.substr(equals + 1u);
        std::uint64_t value = 0u;
        const auto [end, error] = std::from_chars(text.data(), text.data() + text.size(), value);
        const bool valid = error == std::errc{} && end == text.data() + text.size();
        if (key == "frame_us") {
            if (!valid) return std::nullopt;
            sample.frame_us = value;
            have_frame = true;
        } else if (valid && key == "ge_us") {
            sample.ge_us = value;
        } else if (valid && key == "present_us") {
            sample.present_us = value;
        } else if (valid && key == "guest_cpu_us") {
            sample.guest_cpu_us = value;
        }
    }
    if (!have_frame) return std::nullopt;
    return sample;
}

std::optional<std::string> PerfWindow::add(const FrameTimeSample &sample, std::uint64_t memory_used_mb) {
    ++frames_;
    sum_frame_us_ += sample.frame_us;
    max_frame_us_ = std::max(max_frame_us_, sample.frame_us);
    sum_guest_us_ += sample.guest_cpu_us;
    max_guest_us_ = std::max(max_guest_us_, sample.guest_cpu_us);
    sum_ge_us_ += sample.ge_us;
    max_ge_us_ = std::max(max_ge_us_, sample.ge_us);
    sum_present_us_ += sample.present_us;
    max_present_us_ = std::max(max_present_us_, sample.present_us);
    memory_peak_mb_ = std::max(memory_peak_mb_, memory_used_mb);
    if (sum_frame_us_ < window_us_) return std::nullopt;

    elapsed_us_ += sum_frame_us_;
    const double frames = static_cast<double>(frames_);
    const auto average_ms = [frames](std::uint64_t sum_us) { return static_cast<double>(sum_us) / 1000.0 / frames; };
    const auto ms = [](std::uint64_t us) { return static_cast<double>(us) / 1000.0; };
    const double fps_average = frames * 1'000'000.0 / static_cast<double>(sum_frame_us_);
    const double fps_minimum = max_frame_us_ == 0u ? 0.0 : 1'000'000.0 / static_cast<double>(max_frame_us_);

    char text[320];
    std::snprintf(text, sizeof(text),
                  "t=%llus frames=%llu fps_avg=%.1f fps_min=%.1f guest_ms_avg=%.1f guest_ms_max=%.1f "
                  "ge_ms_avg=%.1f ge_ms_max=%.1f present_ms_avg=%.1f present_ms_max=%.1f mem_peak_mb=%llu",
                  static_cast<unsigned long long>(elapsed_us_ / 1'000'000u),
                  static_cast<unsigned long long>(frames_), fps_average, fps_minimum,
                  average_ms(sum_guest_us_), ms(max_guest_us_), average_ms(sum_ge_us_), ms(max_ge_us_),
                  average_ms(sum_present_us_), ms(max_present_us_),
                  static_cast<unsigned long long>(memory_peak_mb_));

    frames_ = 0u;
    sum_frame_us_ = max_frame_us_ = 0u;
    sum_guest_us_ = max_guest_us_ = 0u;
    sum_ge_us_ = max_ge_us_ = 0u;
    sum_present_us_ = max_present_us_ = 0u;
    memory_peak_mb_ = 0u;
    return std::string(text);
}
```

```cpp
#pragma once
// Routes std::cerr on the device: "[frame-time]" lines feed perf.log, every other line goes to
// vcsnx_stderr.log and to the original stderr (nxlink when connected).

#include <functional>
#include <mutex>
#include <streambuf>
#include <string>

namespace vcsnx {

// Hands each complete line (without '\n') to on_line; when it returns true the line is also
// written to `forward`. A partial line waits for its newline.
class LineTeeBuf : public std::streambuf {
public:
    LineTeeBuf(std::streambuf *forward, std::function<bool(const std::string &)> on_line);

protected:
    int_type overflow(int_type ch) override;
    std::streamsize xsputn(const char *text, std::streamsize count) override;
    int sync() override;

private:
    std::streambuf *forward_;
    std::function<bool(const std::string &)> on_line_;
    std::string pending_;
    std::mutex mutex_;
};

// Installs the tee on std::cerr once: <data_dir>/perf.log (appended, one line per 10 s window)
// and <data_dir>/vcsnx_stderr.log (rewritten each session). Later calls do nothing.
void install_stderr_tee(const std::string &data_dir);

} // namespace vcsnx
```

```cpp

#include "memory_usage.hpp"

#include <cstdio>
#include <iostream>
#include <utility>

namespace vcsnx {

LineTeeBuf::LineTeeBuf(std::streambuf *forward, std::function<bool(const std::string &)> on_line)
    : forward_(forward), on_line_(std::move(on_line)) {}

LineTeeBuf::int_type LineTeeBuf::overflow(int_type ch) {
    if (traits_type::eq_int_type(ch, traits_type::eof())) return traits_type::not_eof(ch);
    const char c = traits_type::to_char_type(ch);
    xsputn(&c, 1);
    return ch;
}

std::streamsize LineTeeBuf::xsputn(const char *text, std::streamsize count) {
    std::lock_guard<std::mutex> guard(mutex_);
    for (std::streamsize index = 0; index < count; ++index) {
        if (text[index] != '\n') {
            pending_.push_back(text[index]);
            continue;
        }
        if (on_line_(pending_) && forward_ != nullptr) {
            forward_->sputn(pending_.data(), static_cast<std::streamsize>(pending_.size()));
            forward_->sputc('\n');
        }
        pending_.clear();
    }
    return count;
}

int LineTeeBuf::sync() {
    std::lock_guard<std::mutex> guard(mutex_);
    return forward_ == nullptr ? 0 : forward_->pubsync();
}

void install_stderr_tee(const std::string &data_dir) {
    static std::once_flag once;
    std::call_once(once, [&data_dir] {
        static PerfWindow window;
        static std::FILE *perf = std::fopen((data_dir + "/perf.log").c_str(), "a");
        static std::FILE *log = std::fopen((data_dir + "/vcsnx_stderr.log").c_str(), "w");
        if (perf != nullptr) {
            std::fputs("--- vcsnx session ---\n", perf);
            std::fflush(perf);
        }
        static LineTeeBuf tee(std::cerr.rdbuf(), [](const std::string &line) {
            if (const auto sample = parse_frame_time_line(line)) {
                if (const auto summary = window.add(*sample, memory_used_mb()); summary && perf != nullptr) {
                    std::fputs(summary->c_str(), perf);
                    std::fputc('\n', perf);
                    std::fflush(perf);
                }
                return false; // ~30 lines/s: summarised in perf.log, not forwarded
            }
            if (log != nullptr) {
                std::fputs(line.c_str(), log);
                std::fputc('\n', log);
                std::fflush(log);
            }
            return true;
        });
        std::cerr.rdbuf(&tee);
    });
}
```

```cpp
    if (first == std::string_view::npos) return {};
    const auto last = text.find_last_not_of(" \t\r");

}

std::vector<std::pair<std::string, std::string>> parse_env_lines(std::string_view text) {
    std::vector<std::pair<std::string, std::string>> pairs;
    while (!text.empty()) {
        const std::size_t newline = text.find('\n');
        const std::string_view line = trim(text.substr(0, newline));
        text = newline == std::string_view::npos ? std::string_view{} : text.substr(newline + 1u);
        if (line.empty() || line.front() == '#') continue;
        const std::size_t equals = line.find('=');
        if (equals == std::string_view::npos) continue;
        const std::string_view key = trim(line.substr(0, equals));
        if (key.empty()) continue;
        pairs.emplace_back(std::string(key), std::string(trim(line.substr(equals + 1u))));
    }
    return pairs;
}
```

```cpp
#pragma once
#include <cstdint>

namespace vcsnx {

struct Rect {
    int x{};
    int y{};
    int w{};
    int h{};
};

// Largest rectangle with the source's aspect ratio that fits the output, centred; the rest stays
// black. Integer math, so docked/handheld switches always land on the same pixels.
[[nodiscard]] constexpr Rect letterbox(int output_w, int output_h, std::uint32_t source_w,
                                       std::uint32_t source_h) noexcept {
    if (output_w <= 0 || output_h <= 0 || source_w == 0u || source_h == 0u) return {};
    const long long ow = output_w;
    const long long oh = output_h;
    const long long sw = source_w;
    const long long sh = source_h;
    Rect rect{};
    if (ow * sh > oh * sw) { // output is wider: bars left and right
        rect.h = output_h;
        rect.w = static_cast<int>(oh * sw / sh);
    } else {                 // output is taller (or equal): bars top and bottom
        rect.w = output_w;
        rect.h = static_cast<int>(ow * sh / sw);
    }
    rect.x = (output_w - rect.w) / 2;
    rect.y = (output_h - rect.h) / 2;
    return rect;
}

} // namespace vcsnx
```

```cpp
        g_controller = nullptr;

    if (g_controller == nullptr) {
        for (int index = 0; index < SDL_NumJoysticks(); ++index) {
            if (SDL_IsGameController(index)) {
                g_controller = SDL_GameControllerOpen(index);
                break;
            }
        }

        sample.connected = true;
        sample.buttons = sdl_buttons(g_controller);

        sample.left_y = SDL_GameControllerGetAxis(g_controller, SDL_CONTROLLER_AXIS_LEFTY);
```

```cpp
bool create_window(WindowState &state) {

        std::cerr << "[vcsnx-display] SDL video init failed: " << SDL_GetError() << "\n";

// Swaps the caller's filled buffer in, so neither side allocates per frame.
void publish_pixels(WindowState &state, std::vector<std::uint32_t> &pixels, std::uint32_t width,
                    std::uint32_t height) {
    std::lock_guard<std::mutex> guard(state.mutex);
    std::swap(state.pixels, pixels);
    state.width = width;
    state.height = height;
    state.frame_pending.store(true, std::memory_order_release);
}

void present_pending_frame(WindowState &state) {
    if (!state.frame_pending.exchange(false, std::memory_order_acq_rel)) return;
    std::uint32_t width = 0u;
    std::uint32_t height = 0u;
    {
        std::lock_guard<std::mutex> guard(state.mutex);
        std::swap(state.upload, state.pixels);
        width = state.width;
        height = state.height;
    }
    if (width == 0u || height == 0u || state.upload.size() < std::size_t{width} * height) return;
    const int texture_width = static_cast<int>(width);
    const int texture_height = static_cast<int>(height);
    if (state.texture == nullptr || state.texture_width != texture_width || state.texture_height != texture_height) {
        if (state.texture != nullptr) SDL_DestroyTexture(state.texture);
        state.texture = SDL_CreateTexture(state.renderer, SDL_PIXELFORMAT_RGB888, SDL_TEXTUREACCESS_STREAMING,
                                          texture_width, texture_height);
        state.texture_width = texture_width;
        state.texture_height = texture_height;
        if (state.texture == nullptr) {
            std::cerr << "[vcsnx-display] SDL_CreateTexture failed: " << SDL_GetError() << "\n";
            return;
        }
    }
    SDL_UpdateTexture(state.texture, nullptr, state.upload.data(), texture_width * 4);
    int output_w = 0;
    int output_h = 0;
    SDL_GetRendererOutputSize(state.renderer, &output_w, &output_h);
    const vcsnx::Rect box = vcsnx::letterbox(output_w, output_h, width, height);
    const SDL_Rect destination{box.x, box.y, box.w, box.h};
    SDL_SetRenderDrawColor(state.renderer, 0, 0, 0, 255);
    SDL_RenderClear(state.renderer);
    SDL_RenderCopy(state.renderer, state.texture, nullptr, &destination);

void display_window_start() {
    WindowState &state = window_state();
    if (state.ready.load(std::memory_order_acquire)) return;
    vcsnx::platform_startup();
    state.start_requested.store(true, std::memory_order_release);

void display_window_present(const psprecomp::GuestMemory &memory, const FramebufferDescription &description) {
    WindowState &state = window_state();
    if (!state.ready.load(std::memory_order_acquire)) return;
    std::vector<std::uint8_t> rgb;
    try {
        rgb = decode_framebuffer_rgb(memory, description);
    } catch (const std::exception &) {
        return; // a transient framebuffer pointer outside EDRAM keeps the previous frame on screen
    }
    const std::size_t pixel_count = std::size_t{description.width} * description.height;
    if (rgb.size() < pixel_count * 3u) return;
    static thread_local std::vector<std::uint32_t> packed;
    packed.resize(pixel_count);
    for (std::size_t index = 0; index < pixel_count; ++index) {
        packed[index] = (std::uint32_t{rgb[index * 3u]} << 16u) | (std::uint32_t{rgb[index * 3u + 1u]} << 8u) |
                        std::uint32_t{rgb[index * 3u + 2u]};
    }
    publish_pixels(state, packed, description.width, description.height);
}

void display_window_present_rgba(std::span<const std::byte> rgba, std::uint32_t width, std::uint32_t height) {
    WindowState &state = window_state();
    if (!state.ready.load(std::memory_order_acquire) || width == 0u || height == 0u) return;
    const std::size_t pixel_count = std::size_t{width} * height;
    if (rgba.size() < pixel_count * 4u) return;
    static thread_local std::vector<std::uint32_t> packed;
    packed.resize(pixel_count);
    for (std::size_t index = 0; index < pixel_count; ++index) {
        std::uint32_t source = 0u;
        std::memcpy(&source, rgba.data() + index * 4u, sizeof(source));
        packed[index] = (source & 0x0000FF00u) | ((source & 0x000000FFu) << 16u) | ((source >> 16u) & 0x000000FFu);
    }
    publish_pixels(state, packed, width, height);
}

void display_window_shutdown() {
    WindowState &state = window_state();
    if (!state.ready.load(std::memory_order_acquire)) return;
    state.shutdown_requested.store(true, std::memory_order_release);
    const auto deadline = std::chrono::steady_clock::now() + kShutdownTimeout;
    while (!state.destroyed.load(std::memory_order_acquire) && std::chrono::steady_clock::now() < deadline)
        std::this_thread::sleep_for(std::chrono::milliseconds(10));
}

void display_window_pump_events() {
    WindowState &state = window_state();
    if (state.destroyed.load(std::memory_order_acquire)) return;
    if (!state.ready.load(std::memory_order_acquire)) {
        if (!state.start_requested.exchange(false, std::memory_order_acq_rel)) return;
        if (!create_window(state)) return; // stays headless; display_window_start() times out
        state.ready.store(true, std::memory_order_release);
    }
    SDL_Event event;
    while (SDL_PollEvent(&event)) {
        if (event.type == SDL_QUIT ||
            (event.type == SDL_WINDOWEVENT && event.window.event == SDL_WINDOWEVENT_CLOSE))
            state.close_requested.store(true, std::memory_order_release);
    }
    std::string title;
    {
        std::lock_guard<std::mutex> guard(state.mutex);
        title.swap(state.pending_title);
    }
    if (!title.empty()) SDL_SetWindowTitle(state.window, title.c_str());
    vcsnx::pad_source_pump();
    present_pending_frame(state);
    if (state.shutdown_requested.load(std::memory_order_acquire)) destroy_window(state);
}
```

```cpp
    const u64 held = padGetButtons(&g_pad);
    const auto map = [&sample, held](u64 nx_button, std::uint32_t pad_button) {

    map(HidNpadButton_ZL, kPadZL);
    map(HidNpadButton_ZR, kPadZR);
    map(HidNpadButton_Plus, kPadPlus);
    map(HidNpadButton_Minus, kPadMinus);
    map(HidNpadButton_Up, kPadUp);
    map(HidNpadButton_Down, kPadDown);
    map(HidNpadButton_Left, kPadLeft);
    map(HidNpadButton_Right, kPadRight);
    const HidAnalogStickState left = padGetStickPos(&g_pad, 0);
    const HidAnalogStickState right = padGetStickPos(&g_pad, 1);
    sample.left_x = to_axis(left.x);
    sample.left_y = to_axis(-left.y); // libnx Y grows upward; PadSample grows downward
    sample.right_x = to_axis(right.x);
    sample.right_y = to_axis(-right.y);
    std::lock_guard<std::mutex> guard(g_mutex);
    g_latest = sample;
}
```

```cpp
bool file_exists(const std::string &path) {
    struct stat info {};
    return stat(path.c_str(), &info) == 0 && S_ISREG(info.st_mode);
}

std::string read_text_file(const std::string &path) {
    std::FILE *file = std::fopen(path.c_str(), "rb");
    if (file == nullptr) return {};
    std::string text;
    char buffer[512];
    std::size_t count = 0;
    while ((count = std::fread(buffer, 1, sizeof(buffer), file)) > 0) text.append(buffer, count);
    std::fclose(file);
    return text;
}

[[noreturn]] void show_message_and_exit(const std::string &message) {
    consoleInit(nullptr);
    padConfigureInput(1, HidNpadStyleSet_NpadStandard);
    PadState pad;
    padInitializeDefault(&pad);
    std::printf("\n%s\n", message.c_str());
    while (appletMainLoop()) {
        padUpdate(&pad);
        if ((padGetButtonsDown(&pad) & HidNpadButton_Plus) != 0u) break;
        consoleUpdate(nullptr);
    }
    consoleExit(nullptr);
    std::exit(0);
}

            setenv(key.c_str(), value.c_str(), 1);

        facts.application_mode = type == AppletType_Application || type == AppletType_SystemApplication;
```

```bash
#!/usr/bin/env bash
# Copies the user's PSP_DATA, the VCSNX config and the .nro onto a mounted Switch SD card.
# Usage: tools/prepare_sd.sh <path to PSP_DATA> <SD card root, e.g. /Volumes/SWITCH>
set -euo pipefail
ROOT="$(cd "$(dirname "$0")/.." && pwd)"
DATA="${1:?usage: tools/prepare_sd.sh <path to PSP_DATA> <SD card root>}"
SD="${2:?usage: tools/prepare_sd.sh <path to PSP_DATA> <SD card root>}"
NRO="$(find "$ROOT/build/switch" -name vcsnx.nro -print -quit)"
[ -d "$SD/switch" ] || { echo "$SD does not look like a Switch SD card (no switch/ folder)" >&2; exit 3; }
[ -n "$NRO" ] || { echo "build first: cmake --build --preset switch" >&2; exit 3; }
if [ ! -f "$DATA/EBOOT.BIN" ] && [ ! -f "$DATA/PSP_GAME/SYSDIR/BOOT.BIN" ]; then
    echo "no decrypted ELF under $DATA" >&2; exit 4
fi
DEST="$SD/switch/vcsnx"
mkdir -p "$DEST"
# --delete only inside our own PSP_DATA copy; macOS metadata files are not copied.
rsync -a --delete --exclude='._*' --exclude='.DS_Store' "$DATA/" "$DEST/PSP_DATA/"
cp "$ROOT/config/VCSNative.ini" "$DEST/VCSNative.ini"
cp "$NRO" "$DEST/vcsnx.nro"
dot_clean -m "$DEST" 2>/dev/null || true
echo "SD ready: $DEST ($(du -sh "$DEST" | cut -f1))"
```
